# pbd2json-py

**TJS/ns0（.pbd）解码器与编码器**

## 用法

```bash
python tjs_ns0_decode.py in.pbd out.json              # 解码为 JSON
python tjs_ns0_decode.py in.pbd out.tjs --tjs         # 解码为 TJS 字面量
python tjs_ns0_decode.py in.pbd out.pbd -e in.json    # 从 JSON 编码生成 .pbd
```

## 注意事项

> 本程序仅在 **Python 3.15.2** 上测试过。

> 本程序仅测试过对《天使☆騒々 RE-BOOT！》**v1.11** 的 `.pbd` 文件进行编解码。

> 个人使用过程中尚未遇到编解码错误。

## Kirikiri “TJS NS0” 二进制编码格式

### 文件头

文件头依次包含：

- 魔数：`"TJS/"`
- 变体标识：`"ns0\0"`
- 种子值：32 位小端无符号整数
- 加密标记：16 位无符号整数
- 向量长度：16 位无符号整数

### 主体

主体由带类型标记的变体数据流组成。

16 位标记的计算方式：

```text
标记 = (校验字节 << 8) | 类型字节
```

| 类型 | 类型字节 | 数据格式 |
| --- | --- | --- |
| 空值 | `0x00` | 无额外数据 |
| 字符串 | `0x02` | 32 位长度 + UTF-16LE 数据；长度按 UTF-16 码元计数 |
| 整数 | `0x04` | 64 位小端有符号整数 |
| 双精度浮点数 | `0x05` | 64 位小端浮点数 |
| 数组 | `0x81` | 32 位元素数量 + 各元素数据 |
| 字典 | `0xC1` | 32 位键值对数量 + 键值对；每组包含一个字符串键和一个值 |

### 尾部

尾部为一个 **32 位校验和**，由相同的滚动字节校验算法计算得出。

校验字节由种子值推导而来，作为滚动混淆字节使用。
